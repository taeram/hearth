# Hearth

A set of Docker containers for a Home Theatre PC setup.

## Setup

Create a `.env` file with the following settings:
```
CONTAINERS_PATH="/mnt/f/Containers"
PGID=1000
PUID=1000
QBITTORRENT_VPN_PASSWORD="PASSWORD_GOES_HERE"
QBITTORRENT_VPN_PROVIDER="pia"
QBITTORRENT_VPN_USER="USERNAME_GOES_HERE"
TZ="America/Edmonton"
UNPACKERR_LIDARR_API_KEY="8d8ce28e498f4fse56btb5ydr6ye45fe"
UNPACKERR_RADARR_API_KEY="89639656a235b3w5g6drthg45tyg45t4"
UNPACKERR_SONARR_API_KEY="d5ed7b5c8aawrfs4edgtrh7ubftjfty3"
```
